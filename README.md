One sentence, up to 200 characters, on a small moment of wonder in everyday life — a shadow that beats its owner to the crosswalk, as if it had somewhere better to be.

> "My shadow beat me to the crosswalk by a full step, as if it had somewhere better to be."

## Run it

```sh
node main.ts
```

The program writes the sentence to `/output/entry.txt` (1–200 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
